# Scenarios that cannot exist in Dart

A scenario of the React Native tests (`src/domain` and `src/application`, `*.test.ts`) that has no Dart test, because it cannot exist in Dart. `tool/scenario_parity.dart` does not expect these, and it fails if an entry is not needed (the Dart test exists) or stale (no such React Native test).

One row per scenario: the React Native test file, the full name of the test (the descriptions of its `describe`s and its own, joined with one space; a `|` is written `\|`), and a one-line reason. Only a scenario whose subject does not exist in Dart belongs here: a purely type-level check (`@ts-expect-error`, what the TypeScript compiler refuses), or a mutation of an object that the Dart language makes impossible because its values are immutable (no setter, no growable list). See [../porting.md](../porting.md#7-tests).
